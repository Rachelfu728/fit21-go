# Fit21 出發鍵 (V1.0)

> **「不必想一整天，只要開始第一步。」**  
> 專為體重管理事業經營者打造的行動啟動 PWA 小程序。

---

## 一、產品理念與設計目的

本工具旨在協助擁有 30 多年街頭邀約經驗的經營者，克服**出門前「不想動」、「想到重複邀約就覺得累」的心理摩擦力**。

- **核心原則**：這是一個「降低啟動阻力」的陪伴工具，**不是**業績追蹤或打卡督促系統。
- **3 秒啟動**：首頁極簡無干擾，打開 App 後 3 秒內即可按下「我現在出發」。
- **心理前後對照**：客觀記錄出發前與做完後的累感（1～5分），讓大腦親自看見「實際做完通常沒有出發前想像的那麼累」。
- **溫暖且無壓力**：無連續打卡壓力、無排行榜、不論數字多少，完成畫面只有鼓勵與肯定：「今天最重要的，是妳已經開始。」

---

## 二、視覺設計規範

- **背景色**：奶油白 `#FBF6EC`
- **主色**：深綠 `#0F6E56`
- **輔色**：暖金 `#C9A86A`
- **字體與控制**：繁體中文、高清晰度大按鈕、針對手機單手操作優化。
- **風格**：溫暖、清爽、高級、簡潔，無卡通人物、無過度動效、無 AI 感。

## 三、功能特色

1. **首頁極簡啟動**
   - 標語：「先出發就好。」、「不必想一整天，只要開始第一步。」
   - 出發前感受（選填 1～5 分，可直接跳過）。
   - 醒目深綠大按鈕：「我現在出發」，點擊立即啟動計時。

2. **邀約模式**
   - 顯示今天日期與出發累計時間（自動計時）。
   - **「我已經開口了」** 突破按鈕：點擊記錄今天首次開口時間（如：出發後 4 分鐘），打破心理慣性。
   - 三個核心計數器：
     1. 開口邀約（＋1／－1）
     2. 進店試飲（＋1／－1）
     3. 預約客戶（＋1／－1）
     - 數值不能小於 0。
   - 「結束這次邀約」防誤觸確認機制。
   - **意外重整 / 切換應用恢復**：即使不小心關閉瀏覽器或手機螢幕休眠，重新開啟會自動無縫恢復進行中的計時與計數！

3. **完成畫面**
   - 鼓勵文字：「今天最重要的，是妳已經開始。」
   - 顯示：本次邀約時間、首次開口時間、各項目成果。
   - 完成後感受（選填 1～5 分）。
   - 若出發前與完成後皆有填寫，自動顯示客觀前後對照（例如：出發前 4 分 ➔ 完成後 2 分）。

4. **歷史紀錄與每週統計**
   - 本週統計（本週出發次數、總邀約人數、試飲人數、預約人數、總邀約時間）。
   - 歷史紀錄時間軸（支援同一天多次出發）。
   - 資料保存於手機本機 `localStorage`，不需登入帳號。
   - 提供 JSON 完整備份匯出與匯入功能。

5. **PWA 離線支援**
   - 具備 `manifest.json` 與 `sw.js` (Service Worker)。
   - 支援 Android Chrome「加到主畫面」獨立運行。
   - 全靜態架構，離線斷網依然可以完整操作。

## 四、本地測試方式

專案目錄：`C:\Users\user\.gemini\antigravity\scratch\fit21-go-pwa`

### 方式 1：使用內建 PowerShell 伺服器腳本

在專案目錄下開啟 PowerShell，執行：
```powershell
powershell .\serve.ps1
```
伺服器啟動後，在瀏覽器打開：
`http://localhost:8080/`

### 方式 2：使用任何靜態網頁伺服器
例如 VS Code Live Server、Python (`python -m http.server 8080`) 或直接雙擊 `index.html`。
*(注意：PWA Service Worker 與「加到主畫面」功能在 HTTP / HTTPS 環境下效果最完整)*

## 五、在 Android 手機上安裝 PWA

### 部署建議（免費、支援 HTTPS）：
PWA 在正式環境需要 HTTPS 協定。您可以將此資料夾直接上傳到以下任何免費靜態託管平台：
1. **GitHub Pages**
2. **Cloudflare Pages**
3. **Vercel** / **Netlify**

### Android 手機安裝步驟：
1. 使用手機上的 **Chrome 瀏覽器** 開啟部署後的網址。
2. 點擊瀏覽器右上角的三個點點 **⋮**（選單）。
3. 選擇 **「加到主畫面」** 或 **「安裝應用程式」**。
4. 點選「新增 / 安裝」。
5. 手機桌面上即會出現 **Fit21 出發鍵** 圖示！
6. 點擊桌面圖示即可全螢幕獨立運行，體驗與原生 App 完全相同，且斷網亦可使用。
